# 4d-actuator-measurement

This repository includes a CV pipeline to measure the bending angle of 4D printed and actuated bar shaped objects. The pipeline uses a coin as a reference in the image to obtain the px/mm ratio, to find the accurate value of bending in mm. To run the pipeline, input the name of the image that is to be analysed, and run the whole code. The code will also ask to input the printing parameters used, and will export the data to a CSV file.
